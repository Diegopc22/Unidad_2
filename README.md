Prácticas C# – Administración y Organización de Datos

Este repositorio contiene una serie de prácticas desarrolladas en C# utilizando aplicaciones de consola, realizadas durante el curso de Administración y Organización de Datos (Cuarto Semestre).
El objetivo de estas actividades es reforzar el manejo de validación de datos, control de entradas del usuario y la organización del código mediante distintos métodos y estructuras dentro del lenguaje C#. Cada práctica explora diferentes formas de validar información ingresada por el usuario y garantizar que los datos sean correctos antes de ser procesados.
Organización del repositorio

El repositorio está organizado en varias prácticas, cada una enfocada en diferentes formas de validar y manejar datos dentro de programas de consola.

    • Practica 1-Programa que implementa validaciones básicas de entrada de datos desde la consola. Se enfoca en comprobar que la información ingresada por el usuario cumpla con ciertos criterios antes de continuar con la ejecución del programa.
    • Practica 3-Aplicación que utiliza métodos de validación más estructurados para controlar los datos ingresados por el usuario. Se implementa una mejor organización del código separando la lógica de validación en funciones o clases auxiliares.
    • Practica 4-Programa que amplía el uso de validaciones utilizando distintos métodos para asegurar que los datos introducidos sean correctos. Esta práctica refuerza la reutilización de código y la estructura del programa.
    • Validaciones.cs-Archivo de apoyo que contiene métodos utilizados para validar diferentes tipos de datos, permitiendo reutilizar estas funciones en distintos programas del proyecto.

📚 Temas principales desarrollados- Durante el desarrollo de estas prácticas se trabajaron los siguientes conceptos:

    • Programación en C#
    • Desarrollo de aplicaciones de consola
    • Validación de datos ingresados por el usuario
    • Uso de métodos y funciones para organizar el código
    • Manejo de condicionales para verificar información
    • Reutilización de código mediante archivos auxiliares
    • Organización de programas para mejorar su mantenimiento y comprensión
    
🛠️ Requisitos-Para ejecutar correctamente los programas es necesario contar con:

    • .NET SDK instalado
    • Visual Studio o Visual Studio Code
    • Sistema operativo compatible con .NET 
    • Conocimientos básicos de C# y programación de consola
